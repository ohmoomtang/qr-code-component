## My process

### Built with

- Semantic HTML5 markup
- CSS custom properties (variables)
- CSS styling (padding, margin, border-radius, box-shadow)
- Google Fonts (Outfit)
- Responsive viewport meta tag

### What I learned

I focused on the CSS in `styles.css`. As a backend developer, I found the CSS box model and layout concepts challenging but instructive.

### Continued development

- Practice more Front-End projects
- More familiar with Box Concept, Margin, Padding, and `div` containers
- Explore more options and behaviour (especially with dimensions properties like `width` and `height` )

### Useful resources

- [Learn CSS: Box Model and Layout by Codecademy](https://www.codecademy.com/enrolled/courses/learn-css-box-model-and-layout)
- [CSS Cheat Sheet](https://htmlcheatsheet.com/css/) - While I'm using cheatsheet, it is about to understand the behaviour and affect on each properties/values pair, it is not about to "memorise" the code.
- [Learn CSS](https://web.dev/learn/css/) - Recommended by FE Mentor, I feel this one useful and not that too scary detailed like the MDN one.

### AI Collaboration

Primarily use GitHub Copilot for explaining some concept and help to diagnostic some bug like the \* selector.

**What worked well**

GitHub Copilot helped with small syntax fixes and code snippets I occasionally forget.

**What didn't**

Vague prompts produced unclear answers; I found more precise instructions yielded better assistance.
